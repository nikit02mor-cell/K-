# Решатель от SvinCompany (Android)

Приложение-решатель задач по физике, алгебре, геометрии, химии, вероятности и статистике (решение в формате «Дано / Решение / Ответ»). Открывается на главном экране: приветствие и выбор предмета (химия, алгебра, физика, геометрия, вероятность и статистика). Из любого предмета можно вернуться кнопкой «← Меню».
Это оболочка WebView, внутри лежит страница `app/src/main/assets/index.html`.
Работает без интернета (шрифты IBM Plex подтянутся, если сеть есть, иначе будет системный шрифт).

## Веб-версия

Та же страница лежит в `docs/index.html` (главное меню), физика теперь в `docs/physics.html`. Чтобы открыть её по ссылке: Settings → Pages →
Source: Deploy from a branch → Branch: `main`, папка `/docs`.

### Алгебра, геометрия и химия

Рядом с физикой (`docs/physics.html`) лежат ещё три решателя в том же формате «Дано / Решение / Ответ»:
`docs/algebra.html` (алгебра 7–9 класс) и `docs/geometry.html` (геометрия: треугольники,
четырёхугольники, окружность, правильные многоугольники, координаты, объёмные тела, с чертежами) и `docs/chemistry.html` (химия: молярная масса и состав, количество вещества, формула по массовым долям,
строение атома, растворы и pH, газовые законы, уравнивание реакций, расчёты по уравнениям, избыток и недостаток;
переключатель школьных и точных атомных масс).
У каждой страницы свой манифест и service worker (`manifest-geometry.webmanifest`, `sw-geometry.js`, то же для `physics` и `chemistry`; у меню свои `manifest.webmanifest` и `sw.js`),
поэтому на iPhone их можно установить как отдельные приложения. Между страницами есть ссылки.
В APK входят все четыре предмета: страницы берутся прямо из `docs/` (отдельной копии в `assets` больше нет, править нужно только `docs/`).

### Вероятность и статистика

Отдельная страница `docs/probability.html` (манифест `manifest-probability.webmanifest`, service worker `sw-probability.js`), четыре раздела:
- **Вероятность:** классическая вероятность, игральные кости (с диаграммой), два события (и / хотя бы одно / ровно одно / несовместные), «хотя бы одно за n попыток», условная вероятность и формула Байеса.
- **Комбинаторика:** перестановки, перестановки букв слова (с повторами), размещения и сочетания, в том числе с повторениями. Значения считаются точно (BigInt), n до 100.
- **Распределения:** схема Бернулли (с диаграммой распределения) и дискретная случайная величина (M, D, σ).
- **Статистика:** среднее, медиана, мода, размах; дисперсия и σ (генеральная и выборочная); таблица частот; гистограмма по интервалам; квартили, IQR и выбросы («ящик с усами»); среднее взвешенное; корреляция и прямая регрессии с прогнозом.

Числа в списках вводятся через пробел или `;`. Допустимы десятичная запятая и обыкновенные дроби (`1/4`) в вероятностях.
Квартили считаются методом медиан половин (школьный способ).

### Тригонометрия, стереометрия (внутри геометрии) и метод интервалов

- `docs/trigonometry.html` (манифест `manifest-trigonometry.webmanifest`, `sw-trigonometry.js`): градусы и радианы, sin/cos/tg/ctg любого угла (точные значения √2/2, √3/2…), точка на единичной окружности, функции по одной известной, арксинус/арккосинус/арктангенс; формулы сложения, двойного и половинного угла, приведения, суммы и произведения; уравнения `cos x = a`, `sin x = a`, `tg x = a` (с отбором корней на промежутке), `a·sin x + b·cos x = c`, однородные, квадратные относительно sin/cos/tg; неравенства `sin x`, `cos x`, `tg x` ∨ a. Угол вводится числом (градусы) или с π (радианы): `150`, `5π/6`, `1,2 рад`; числа можно писать как `√3/2`, `1/2`.
- Стереометрия теперь в `docs/geometry.html` (категории «Многогранники», «Тела вращения», «Векторы в пространстве»): правильная призма, параллелепипед, правильная пирамида (по высоте, ребру, апофеме или углам), усечённая пирамида, правильные многогранники, усечённый конус, цилиндр и конус с вписанным и описанным шарами, шаровой сегмент, сектор и слой, сечение шара; расстояния, скалярное и векторное произведения, плоскость по трём точкам, углы между прямыми и плоскостями, объём пирамиды по четырём точкам, расстояние между скрещивающимися прямыми. Точки и векторы вводятся тремя числами через пробел.
- В `docs/algebra.html` появился раздел «Метод интервалов»: по готовым корням (с кратностью и выколотыми точками) и по многочленам `P(x)/Q(x)` (корни ищутся среди рациональных, остаток раскладывается как квадратный трёхчлен или находится численно), с числовой осью и знаками.

### Установка на iPhone / iPad (PWA)

Веб-версия работает как установленное приложение и без интернета:
1. Откройте ссылку на сайт в **Safari**.
2. Нажмите «Поделиться» → «На экран “Домой”».

На Android в Chrome то же самое: меню ⋮ → «Установить приложение».

Файлы PWA лежат в `docs/`: `manifest.webmanifest`, `sw.js` (офлайн-кэш), `icons/`.
Чтобы выпустить обновление, правьте нужную страницу в `docs/` и увеличьте номер в `CACHE` в её service worker (для физики `docs/sw-physics.js`)
(например, `v1` → `v2`). Страница сначала берётся из сети, поэтому у друзей с интернетом
обновление появляется само, без переустановки. Для APK нужна отдельная сборка, APK пересобирается автоматически при каждом пуше в `main` (Actions → Build APK).

## Как получить APK

### Вариант 1. Android Studio
1. Установите Android Studio: https://developer.android.com/studio
2. File → Open → выберите эту папку, дождитесь синхронизации Gradle.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Скопируйте на телефон и откройте
   (разрешите установку из неизвестных источников).

### Вариант 2. Командная строка
Нужны JDK 17+ и Android SDK (переменная ANDROID_HOME):
    ./gradlew assembleDebug        (Windows: gradlew.bat assembleDebug)

### Вариант 3. Без установки программ (GitHub)
Создайте репозиторий на GitHub, загрузите туда содержимое папки, откройте вкладку Actions →
«Build APK» → Run workflow. Через несколько минут APK можно скачать из раздела Artifacts.

Если нужно менять приложение, правьте `app/src/main/assets/index.html`.
Debug-APK подходит для личной установки. Для публикации в Google Play нужна подпись release-ключом.

## Git

Репозиторий уже создан (`git init`, ветка `main`), `.gitignore` для Android настроен.
Чтобы сохранить первую версию и отправить на GitHub (папка `.git` уже внутри):

    git add -A
    git commit -m "Физика от SvinCompany: первая версия"
    git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
    git push -u origin main

Если Git просит представиться, один раз выполните:

    git config --global user.name "Ваше имя"
    git config --global user.email "ваша@почта"

## Реклама и заработок

Реклама подготовлена, но **пока выключена**: нужны ваши рекламные аккаунты Google.

**Сайт (Google AdSense).**
1. Подайте сайт на https://adsense.google.com. Адреса `*.github.io` AdSense обычно не одобряет, поэтому нужен свой домен
   (его можно подключить к GitHub Pages: Settings → Pages → Custom domain).
2. После одобрения создайте адаптивный блок, возьмите `ca-pub-…` и номер блока.
3. Впишите их в начало `docs/ads.js` (`client` и `slot`). Пока поля пустые, реклама не грузится и место под неё скрыто.

**Android (Google AdMob).**
1. Зарегистрируйтесь на https://admob.google.com, добавьте приложение и создайте баннерный блок.
2. В `app/src/main/res/values/strings.xml` замените `admob_app_id` и `admob_banner_id`.
   Сейчас там тестовые ID Google: баннер виден, но доход не идёт. **Нельзя нажимать на свою рекламу** с боевыми ID, аккаунт заблокируют.
3. Для публикации в Google Play нужна политика конфиденциальности и анкета «Безопасность данных» (укажите рекламу и рекламный ID).
   Для пользователей из ЕС и Великобритании AdMob требует окно согласия (Google UMP); если аудитория только в России, это не критично.

Реклама в APK работает только в нативном баннере; AdSense внутри WebView запрещён правилами Google, поэтому страницы в приложении его не грузят.
